# Venera Community 1.7.0 Beta 1

这是一次覆盖阅读器、下载、本地漫画、网络访问、数据同步、Android、Windows 与桌面 UI 的大版本测试更新。它不是上游官方 Venera 发布，而是 Venera Community 的公开 Beta。

> Beta 提示：此版本包含数据库、Cookie、下载恢复和存储迁移逻辑调整。安装前建议先在旧版本中导出一份本地备份。请勿在没有额外备份的情况下让原版与社区版同时写入同一个手工指定的共享漫画目录。

## 安装与升级

- Android 社区版永久包名仍为 `io.github.casthan321.venera`，可直接覆盖升级 Venera Community 1.6.4/1.6.5，并可与上游官方包 `com.github.wgh136.venera` 共存。
- Android 提供 universal、arm64-v8a、armeabi-v7a 与 x86_64 APK；不确定设备架构时请选择 universal APK。
- Windows 提供 x64 便携 ZIP 与 Inno Setup 安装器。Beta 安装器当前没有商业 Authenticode 证书，Windows SmartScreen 可能提示未知发布者；请先核对 Release 中的 SHA-256。
- Beta 版本使用与正式版兼容的语义化版本比较，未来 `beta.2`、RC 和正式 `1.7.0` 可以正常识别升级顺序。
- 1.6.x 正式版默认不会被自动引导到 Beta；希望参与测试的用户可手工安装本页资产，或在“关于”中开启“接收 Beta 测试版更新”。已经安装 Beta 的用户会继续收到后续 Beta/RC 提示。

## 阅读器

- 修复连续条漫快速拖动进度后阅读区永久无法滚动的问题。进度条仅在松手时提交最终页，连续模式使用安全跳转，并增加动画令牌、超时、退出清理和最终位置校正。
- 修复画廊模式拖动进度、收起工具栏后图片看似重新加载或永久转圈的问题，改用稳定的项目图片组件承载 PhotoView。
- 连续模式按可视面积最大的图片计算当前页，不再被上一页残边干扰历史记录和预加载。
- 下一页会提前下载并解码，其余前瞻页只预下载；已下载页靠近时会升级为预解码，减少长图首次出现的布局重排与卡顿。
- 画廊与连续模式统一预加载去重，限制控制器、图片尺寸和解码缓存范围，修复监听器、计时器与异步内存探测的生命周期泄漏。
- 修复关闭翻页动画后手势仍有弹道动画、滑动结束误弹工具栏、历史页码超过当前图片数、章节请求永久加载、下载漫画无法收藏图片等问题。
- 修复历史封面失效后的自动刷新与详情页旧封面覆盖新封面。
- GIF 根据内容签名绕过静态图片分块脚本，避免 JM 等来源的动图被错误拆分或静态化。

## 下载与本地漫画

- 重写图片列表恢复状态机：部分章节、空列表、超时、暂停/继续和旧请求晚返回都不会再被误标为下载完成。
- 图片和封面使用 `.venera-part` 临时文件、flush 与原子重命名；启动恢复会清理残片、零字节文件并完整重扫页索引。
- 下载目录加入来源与漫画身份 marker，可安全找回任务 JSON 丢失后的未完成目录，避免无意义创建 `(1)` 重复目录。
- 下载队列 JSON 改为合并写入与原子替换，删除逐页重写完整 URL 列表的高频 I/O；单条坏任务只隔离自身，不再清空整个队列。
- 通用文件下载器支持 HEAD 不可用回退、严格 Range/Content-Range 校验、ETag/Last-Modified 恢复、真实取消、流式随机写、限频 checkpoint 与安全单流降级。
- 归档下载采用 staging → backup → publish 事务；取消、解压、验证、数据库提交或发布失败都会恢复旧漫画。
- ZIP/CBZ/7Z 加入路径穿越、大小写碰撞、重复条目、条目数、路径深度、单文件/总大小和压缩比预算，阻止 ZIP bomb 与跨目录覆盖。
- CBZ/7Z 导入使用唯一 staging 和冲突安全目录，修复标题净化碰撞、Windows 保留名、章节全部落入 `0`、失败后孤儿目录与部分注册。
- 存储路径迁移会暂停并排空下载、重定位队列和绝对漫画路径、原子提交配置；失败逆序回滚，迁移期间的新任务延后启动。
- 修复自定义路径首次封面回退、本地非图片文件崩溃、批量删除生命周期、嵌套 `downloads` 目录、已有下载记录但目录缺失等问题。

## 网络、网页与访问可靠性

- RHttp 客户端按传输配置复用连接池，设置变更后安全换代；支持连接、发送、首响应头与流空闲超时，以及贯穿原生请求的取消。
- HTTP 重定向改为逐跳可观察处理，中间 `Set-Cookie` 可正确保存；跨域时剥离 Authorization、Cookie、API key、token、session 等敏感头。
- 307/308 和 WebDAV 流式 PUT 使用可重开的文件流；不可安全重放的单订阅流会明确失败，不再悄悄上传空内容。
- 网络缓存纳入响应类型与 `Vary`，只缓存完整 200 响应；认证、Cookie、Set-Cookie、敏感查询、`no-store`、`no-cache` 与私有响应不缓存。
- 日志默认脱敏 URL、header、查询参数、Cookie、token 与请求体；二进制内容只记录大小，Cloudflare 页面不再记录 DOM。
- Cookie 实现增加 Secure、`__Secure-`、`__Host-`、Max-Age、默认 Path、路径边界、host-only 与 PSL 校验；合法父域登录可跨子域使用，公共/私有后缀注入会被拒绝。
- Cloudflare 检测采用标准响应头和保守特征，同源验证只保存服务端真实颁发的 clearance 与对应 UA；取消不会重试，也不会自动化或绕过 CAPTCHA。
- WebView 增加 DNS/代理/HTTP/TLS 分阶段错误页、重试和外部浏览器入口；TLS 错误始终拒绝，不会自动关闭证书校验。
- Windows/Android 系统代理保留 HTTP 与 HTTPS 分流；PAC/绕过规则在应用网络栈无法可靠执行时明确 fail closed，WebView2 仍交给系统解析。

## 数据、历史与同步

- appdata、下载队列、WebDAV 临时文件和关键状态改为原子写入；历史与本地库增加常用查询索引及小型 LRU 缓存。
- SQLite worker 不再跨 Isolate 传裸连接指针；每个 worker 独立打开连接、设置 busy retry 并在 finally 关闭。
- 导入会先验证 SQLite integrity/schema，再以 staging 和备份事务替换；管理器关闭、重开、JS 引擎和来源重载均有失败回滚。
- 导入、WebDAV 上传/下载和存储迁移共享公平、可重入的独占维护锁，避免旧快照覆盖新导入或在数据库替换时继续写入。
- WebDAV 备份按数值版本排序，检测同版本分叉，先流式上传临时文件并校验大小，再 rename 和提交版本，最后保守清理旧备份。
- 云同步归档不再包含 Cookie 数据库、代理/WebDAV 凭据和设备专属设置；本地手工备份仍按明确的本地恢复规则处理。
- 收藏页的大数据异步刷新使用合并调度，不再丢失加载期间的收藏事件；搜索状态也会同步重算。

## Android

- 分享入口支持 `text/*`、Spanned/CharSequence 和 `onNewIntent`，待处理队列有上限。
- 文件与目录选择、DocumentFile 枚举和复制移到串行 I/O executor；结果只在主线程返回，失败清理半成品。
- SAF 路径使用 DocumentsContract 正确处理主存储与可移除卷；权限请求合并，并为不支持专属设置页的 OEM 提供回退。
- 临时文件按文件/目录隔离、唯一命名并清理七天以上遗留；加入路径、深度和目录穿越防护。
- 修复 EventChannel、后台线程与 Flutter engine 销毁后的回调泄漏，并补充 Android 10 兼容存储声明。

## Windows 与桌面 UI

- 窗口位置由 100ms 轮询改为 move/resize/maximize 事件加防抖保存，支持负坐标副屏、离线显示器恢复与尺寸夹取。
- 关闭窗口不再直接 `exit(0)`；导入、同步或迁移提交期间会阻止强制关闭，普通退出先保存窗口状态并走完整生命周期。
- 移除 5 秒 UI 心跳强杀，修复 WinHTTP 内存初始化/UTF-8/释放、剪贴板位图所有权、XButton、COM、DPI 与长路径问题。
- WebView2 环境按代理配置共享且失败可重试，Release 禁止 inspect，桌面轮询防重入。
- 安装器使用独立 Community AppId、非管理员安装与完整递归打包，不再删除或覆盖上游原版目录。
- ARM64 构建会验证真实 ARM64 主机并清除旧产物；x64 主机不会再误打包陈旧 ARM64 文件。
- 设置页、探索页、搜索、历史与下载中心增加宽屏布局、空状态、批量操作确认、请求代次保护、Tooltip 和 Semantics。

## Beta 验证与反馈

发布流水线会在公开前强制执行 Dart 格式检查、全仓 `flutter analyze`、完整 Flutter 测试、Android release 签名证书指纹核验、APK 签名验证、Windows x64 Release 构建及所有产物 SHA-256 生成。任何一个步骤失败都不会发布 Release。

建议重点测试：

1. 连续条漫快速拖进度、快速滚动和跨章节加载。
2. 画廊进度跳转、缩放、收起工具栏与关闭动画后的翻页。
3. 大章节暂停/继续、杀进程恢复、取消与重新下载。
4. WebDAV 上传、下载、重定向、同版本冲突与失败回滚。
5. Android SAF/SD 卡迁移与 Windows 多显示器、WebView2 和安装器升级。

反馈时请附平台、系统版本、阅读模式、来源版本、复现步骤，以及设置 → Debug 中已脱敏的相关日志。请不要公开 Cookie、账号、Authorization、签名下载链接或代理密码。
