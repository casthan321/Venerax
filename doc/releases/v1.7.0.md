# Venera Community 1.7.0 正式版

Venera Community 1.7.0 是一次覆盖阅读器、下载、本地漫画、网络访问、数据安全、Android、Windows 与桌面体验的大版本正式更新。该版本基于公开 Beta 的完整双平台构建和回归结果收口，仍是独立的社区维护分支，并非上游官方 Venera 发布。

> 升级建议：本次更新调整了数据库访问、Cookie、下载恢复、压缩包导入和存储迁移流程。升级前建议先在旧版本中导出一份本地备份。不要让官方版与社区版同时写入同一个手工指定的共享漫画目录。

## 安装、升级与旧版本更新

- Android 永久包名保持 `io.github.casthan321.venera`，可覆盖升级 Venera Community 1.6.4、1.6.5 和 1.7.0 Beta 1，并可与官方包 `com.github.wgh136.venera` 共存。
- 正式版使用构建号 `171`：universal APK 的 versionCode 为 1710，armeabi-v7a、arm64-v8a、x86_64 分别为 1711、1712、1713，均高于 Beta 版本。
- Android 提供 universal、arm64-v8a、armeabi-v7a 与 x86_64 APK；现代 Android 手机通常选择 arm64-v8a，不确定架构时选择 universal。
- Windows 提供 x64 安装器与便携 ZIP。安装器目前没有商业 Authenticode 证书，SmartScreen 可能显示未知发布者，请从本 Release 下载并核对 SHA-256。
- Windows 1.7.0 Beta 1 使用相同的 Community 安装器身份，可以由正式版安装器原位升级。Windows 1.6.5 仍沿用早期/上游安装器身份，正式版会作为独立应用安装；请先在旧版导出备份，再在 Community 正式版导入，确认数据后自行卸载旧应用。正式版不会接管或删除旧版目录。
- 1.6.4/1.6.5 用户如果已经开启“启动时检查更新”，会在 `master` 发布稳定版本信息后收到提示；其他用户可进入“设置 → 关于 → 检查更新”。旧客户端只打开 GitHub Release 页面，不会静默下载或安装 APK。
- 正式版不会要求用户开启“接收 Beta 测试版更新”；已安装 Beta 的用户也会正常识别 `1.7.0` 为更高版本。

## 阅读器与图片性能

- 修复连续条漫拖动进度后无法继续滚动，以及画廊跳页、收起工具栏后图片假重载或永久转圈。
- 连续模式按可视面积最大的图片确定当前页，避免上一页残边干扰历史记录、进度和预加载。
- 下一页提前下载并解码，其余前瞻页只预下载；页面靠近时再升级为预解码，减少长图首次出现时的布局重排与卡顿。
- 画廊与连续模式统一预加载去重，限制控制器、尺寸缓存和解码缓存，清理监听器、计时器及异步内存探测生命周期。
- 修复关闭翻页动画后手势仍有弹道动画、滑动结束误弹工具栏、历史页码超过图片数、章节请求永久加载和下载漫画不能收藏图片。
- 历史封面失效后自动刷新；GIF 按内容签名绕过静态图片处理，避免动图被错误拆分或静态化。

## 下载、归档与本地漫画

- 重写图片列表恢复状态机，部分章节、空列表、超时、暂停/继续和旧请求晚返回不再被误标为完成。
- 图片与封面通过 `.venera-part`、flush 和原子重命名发布；恢复时清理残片、零字节文件并重新核对页索引。
- 下载目录加入来源/漫画身份 marker，任务记录丢失后可以安全复用未完成目录，减少重复 `(1)` 目录。
- 下载队列采用合并写入和原子替换，取消逐页重写完整 URL 列表；坏任务只隔离自身。
- 文件下载器支持 HEAD 回退、严格 Range/Content-Range、ETag/Last-Modified、真实取消、限频 checkpoint、安全单流降级和逐跳重定向。
- 归档下载采用 staging → backup → publish 事务；取消、解压、验证、数据库写入或发布失败时恢复原漫画。
- ZIP、CBZ 与 7Z 导入增加路径穿越、名称碰撞、重复条目、路径深度、条目数、单文件/总大小及压缩比预算，阻止跨目录覆盖和 ZIP bomb。
- 存储路径迁移会暂停并排空下载，原子更新队列、数据库与配置；失败按相反顺序回滚，并保留必要副本用于恢复。

## 网络、网页与访问可靠性

- RHttp 客户端按传输配置复用连接池，补齐连接、发送、首响应头、响应流空闲超时和贯穿原生请求的取消。
- HTTP 重定向逐跳处理，中间 `Set-Cookie` 可被保存；跨域时移除 Authorization、Cookie、API key、token、session 等敏感头。
- WebDAV 和文件下载支持可重开的 307/308 请求体，不可安全重放的单订阅流会明确失败。
- 缓存区分响应类型与 `Vary`，仅保存完整 200 响应；认证、Cookie、敏感查询、`no-store`、`no-cache` 和私有响应不缓存。
- 网络日志默认脱敏 URL、查询、header、Cookie、token 与请求体；二进制内容仅记录大小，Cloudflare 页面不记录 DOM。
- Cookie 增加 Secure、前缀规则、Max-Age、默认 Path、路径边界、host-only 与公共后缀校验，同时支持合法父域登录跨子域使用。
- Cloudflare 验证保持用户可见，不自动化或绕过 CAPTCHA；只保存同源服务端真实颁发的 clearance 与对应 UA。
- WebView 增加 DNS、代理、HTTP、TLS 分阶段错误页以及安全重试/外部浏览器入口；TLS 错误不会自动关闭证书校验。
- Windows 与 Android 系统代理保留 HTTP/HTTPS 分流；应用网络栈不能可靠执行 PAC 时明确失败，WebView2 继续使用系统解析。

## 数据、同步与恢复

- appdata、下载队列、WebDAV 临时文件和关键状态改为原子写入；历史与本地库增加索引及小型 LRU 缓存。
- SQLite worker 各自打开连接、设置 busy retry 并在 finally 关闭，不再跨 Isolate 共享裸数据库指针。
- 数据导入先验证数据库完整性与 schema，再通过 staging/备份事务替换；失败会恢复管理器、JS 引擎、来源与旧数据。
- 导入、WebDAV 和存储迁移共享独占维护锁，并为应用数据导入和本地路径迁移写入持久恢复 journal，异常退出后可继续提交或回滚。
- WebDAV 按数值版本选择备份，检测同版本分叉；先流式上传临时文件并核对大小，再重命名和提交版本。
- 云同步不再包含 Cookie 数据库、代理/WebDAV 凭据和设备专属设置。
- 收藏页的大数据异步刷新采用合并调度，加载期间的新收藏事件与搜索结果不会丢失。

## Android、Windows 与界面

- Android 分享支持 `text/*`、Spanned/CharSequence 和 `onNewIntent`；文件/目录选择、DocumentFile 枚举与复制移至串行 I/O executor。
- SAF 正确处理主存储与可移除卷；权限请求合并，并为不支持专属设置页的 OEM 提供回退。
- 临时文件按任务隔离并清理遗留内容，增加路径、深度和目录穿越保护；修复 EventChannel、后台线程与 engine 销毁后的回调泄漏。
- Windows 窗口状态改为事件驱动加防抖保存，支持负坐标副屏、离线显示器恢复和尺寸夹取。
- Windows 退出不再直接 `exit(0)`；数据事务提交期间阻止强制关闭，普通退出完整保存状态。
- 修复 WinHTTP、剪贴板所有权、XButton、COM、DPI、长路径和 WebView2 环境复用问题。
- Windows 安装器使用独立 Community AppId、非管理员安装和递归打包，不删除或覆盖官方版目录。
- 设置、探索、搜索、历史和下载中心改进宽屏布局、空状态、批量确认、异步请求代次、Tooltip 与 Semantics。

## 发布验证

正式版在公开前必须通过：锁定依赖解析、Dart 格式检查、全仓 `flutter analyze`、完整 Flutter 测试、Android 永久签名证书指纹核验、四个 APK 签名验证、Windows x64 Release/安装器构建、R8 mapping 保存，以及 Android/Windows 两份 SHA-256 清单生成。任何必需步骤失败，Release 都不会公开。

反馈问题时请附平台、系统版本、阅读模式、来源版本、复现步骤和“设置 → Debug”中的相关脱敏日志。请勿公开 Cookie、账号、Authorization、签名下载链接或代理密码。
